# 房间监听

`0.2.5`起新增独立房间监听窗口。该窗口用于查看当前 NRL 服务器上的全部可见房间，并可选择性收听房间语音；已登录用户还可以加入房间。

---

## 功能入口

在主窗口顶部工具栏点击：

```text
监听
```

即可打开独立窗口。英文界面显示为：

```text
Monitor
```

监听窗口大小约为 `1040 x 720`，可拖动缩放；再次点击顶部入口会聚焦已有窗口。

---

## 监听服务器

监听窗口始终使用主界面当前选择的 **NRL 语音服务器**，没有单独的监听服务器配置。

- 主窗口切换 NRL 服务器后，监听窗口会自动断开旧 WebSocket；
- 然后使用新的服务器地址重新连接；
- 主界面上次连接的服务器也会在应用启动时自动恢复连接。

---

## 登录与房间可见性

监听不需要登录。

| 状态 | 可见房间 | 可收听 | 可加入 |
| --- | --- | --- | --- |
| 未登录 | 公共房间 | 公共房间 | 否 |
| 已登录 | 公共房间 + 当前账号有权限的房间 | 有权限的房间 | 是 |

一些房间要求登录或特定权限。未登录时，服务器的 WebSocket 快照只返回公共房间；登录后，服务端会额外下发当前账号有权限访问的房间。

加入房间是管理操作，需要当前服务器登录态；未登录时 `加入` 按钮不可用。

---

## WebSocket 数据流

监听窗口连接当前 NRL 服务器：

```text
wss://<NRL服务器>/ws/calls?token=<token>
```

未登录时使用匿名连接：

```text
wss://<NRL服务器>/ws/calls
```

本地开发或非 HTTPS 服务时使用：

```text
ws://<NRL服务器>/ws/calls
```

连接后会处理以下消息：

| 消息类型 | 说明 |
| --- | --- |
| `snapshot` | 连接建立后的房间快照、订阅列表、统计信息 |
| `rooms` | 房间列表刷新，包含在线人数变化 |
| `room_state` | 单个房间状态更新，例如开始通话、结束通话 |
| `subscriptions` | 当前窗口的订阅房间列表 |
| `stats` | 在线设备、收听数、连接数统计 |
| `pong` | 心跳响应 |

每 10 秒发送一次：

```json
{
  "action": "ping"
}
```

如果 WebSocket 断开，窗口会在 2 秒后自动重连。

---

## 收听房间

每个房间卡片底部有：

```text
收听
```

点击后发送：

```json
{
  "action": "subscribe",
  "room_keys": ["public:0"]
}
```

再次点击发送取消订阅：

```json
{
  "action": "unsubscribe",
  "room_keys": ["public:0"]
}
```

收听中的按钮显示为：

```text
收听中
```

按钮颜色较淡；房间边框本身会通过绿色发光闪烁提示正在通话。

---

## 加入房间

已登录时，非当前房间会显示：

```text
加入
```

点击后调用 NRL 管理接口，把当前设备切换到目标房间。加入成功后：

- 本地当前群组同步更新；
- 房间卡片会显示 `当前群组`；
- 后续语音加入目标房间。

未登录或账号没有权限时，加入会失败或按钮不可用。

---

## 房间卡片信息

每个房间卡片显示：

- 房间 ID 和名称；
- 房间类型，例如公共、中继互联、会议组、私密房间；
- 在线设备数；
- 正在通话时的说话人列表；
- 当前状态：空闲或说话人信息；
- 当前群组标记；
- 收听 / 加入操作。

正在通话的房间会以绿色边框发光闪烁提示。

---

## 音频播放

监听窗口接收 WebSocket 二进制帧：

- 服务端只下发已订阅房间的混音；
- 音频为 G.711 A-law，8kHz，单声道；
- 客户端解码为 PCM 后通过 WebAudio 播放；
- 音频使用轻量调度，避免多个 20ms 帧到达时产生爆音。

窗口右上角可以开关音频：

```text
音频开 / 音频关
```

关闭音频后，WebSocket 仍保持连接，房间状态仍会更新，只是暂停本窗口的监听播放。

---

## 与主窗口的关系

监听窗口和主窗口互相独立：

| 事项 | 说明 |
| --- | --- |
| 语音服务器 | 共用主界面当前选择的 NRL 服务器 |
| 管理登录 | 读取当前已保存的平台登录态 |
| 房间收听 | 只在监听窗口内订阅和播放 |
| 主窗口 PTT | 不影响监听窗口的订阅状态 |
| 加入房间 | 更新设备群组，主窗口配置会同步保存 |
| 服务器切换 | 监听窗口自动跟随主窗口当前 NRL 服务器 |

## 常见问题

### 看不到某些房间

可能原因：

1. 未登录；
2. 当前账号没有该房间权限；
3. 房间是其他用户的私密房间；
4. 服务器未开启或房间列表尚未同步。

### 能看到房间但收听不到声音

检查：

1. 是否点击了 `收听`；
2. 窗口右上角是否为 `音频开`；
3. 系统输出设备是否正确；
4. 房间内是否真的有人说话；
5. WebSocket 是否保持连接。

### 一直在“正在连接服务器”

可能原因：

1. 当前 NRL 服务器不可达；
2. WebSocket 服务未启动；
3. 服务器证书异常；
4. 反向代理没有正确转发 `/ws/calls`；
5. 网络或防火墙阻断 WebSocket。

### 加入失败

可能原因：

1. 未登录当前服务器；
2. 登录态已过期；
3. 当前账号没有权限加入；
4. 房间密码或访问限制不允许当前设备加入；
5. 设备尚未在服务器上建档。
