常见问题 / FAQ

1. 无法登录平台账号 / Cannot sign in

  • 确认已选择正确的平台服务器（登录页「服务器列表」），并使用平台主站账号。
  • 持有 HAM ID 长期 Token 的用户可在「Token」页签登录。
  • 账号注册与注销请在 NRL 平台主站或其 iOS 客户端完成；macOS 商店版仅提供登录。

2. 连接后听不到声音 / No audio after connecting

  • 在系统设置中允许本应用访问麦克风（隐私 → 麦克风）。
  • 在应用「配置」面板确认输入/输出设备与采样率（默认 8000 Hz）。
  • 检查网络质量指示（延迟/丢包），必要时切换服务器或群组。

3. PTT 无法发射 / PTT not transmitting

  • 默认热键为空格，可在「配置 → PTT 热键」自定义。
  • 确认已连接群组且账号具备发射权限；短按切换、长按持续发射。

4. 商店版功能差异 / App Store build differences

  • 受 App Sandbox 限制，Mac 商店版不支持串口透传；录音仅可写入应用容器或您授权的目录。
  • 商店版不含内置自动更新，更新经由 App Store 分发。

5. 账号删除 / Account deletion

  • macOS 商店版不提供账号创建；如需删除平台账号，请在 NRL 平台主站（www.nrlptt.com）联系管理员，或使用 iOS 客户端的账号管理功能，也可通过支持邮箱协助处理。

NRL Pulse (NRL互联) is an amateur-radio / emergency-communication voice client supporting NRL2 and FMO protocols.
